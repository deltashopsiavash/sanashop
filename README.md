# SanaShop — فروشگاه اکسسوری با مدیریت تلگرام

فروشگاه فارسی و واکنش‌گرا برای Ubuntu 24.04 با مدیریت محصولات، دسته‌ها، قیمت، موجودی، سفارش‌ها و تنظیمات از ربات تلگرام. نام و هویت فروشگاه از دیتابیس خوانده می‌شود؛ بنابراین تغییر «سنا» به هر نام دیگری از ربات، در تمام ویترین اعمال می‌شود.

## امکانات نسخه فعلی

- ویترین RTL، جست‌وجو، دسته و زیردسته، صفحه محصول، سبد خرید و تسویه‌حساب مهمان
- مدیریت دسته، محصول، عکس، قیمت، موجودی و فعال/غیرفعال‌کردن از تلگرام
- مدیریت سفارش‌ها و تغییر وضعیت به پرداخت‌شده، آماده‌سازی، ارسال‌شده یا لغوشده
- زرین‌پال (واقعی یا Sandbox) و کارت‌به‌کارت؛ انتخاب یکی یا هر دو از ربات/پنل
- آپلود امن رسید JPG/PNG/WEBP تا ۸ مگابایت و ارسال فوری تصویر برای مدیر در تلگرام
- تغییر نام سایت، نوار اعلان، شماره کارت و روش پرداخت از ربات
- پنل اضطراری Django در `/admin/` برای تنظیمات کامل، اینماد و ویرایش گروهی
- صفحات قوانین، مرجوعی، حریم خصوصی، تماس و جایگاه کد اینماد
- PostgreSQL، HTTPS خودکار با Caddy، هدرهای امنیتی و نگهداری خصوصی رسیدها
- نصب، آپدیت، پشتیبان‌گیری، بازگشت نسخه و مشاهده لاگ با فرمان ثابت

## نصب روی Ubuntu 24.04

ابتدا رکورد `A` دامنه را روی IP سرور بگذارید، در BotFather ربات بسازید و آیدی عددی مدیر را آماده کنید. سپس:

```bash
curl -fsSL https://raw.githubusercontent.com/deltashopsiavash/sanashop/main/install.sh | sudo bash
```

نصب‌کننده دامنه، ایمیل SSL، توکن ربات، آیدی مدیر، نام فروشگاه، اطلاعات کارت و مرچنت زرین‌پال را می‌پرسد. رمزها در فایل `/opt/sanashop/.env` با دسترسی محدود ذخیره می‌شوند و داخل Git قرار نمی‌گیرند.

اگر ورودی تعاملی در دسترس نیست، متغیرها را قبل از اجرای اسکریپت تعریف کنید؛ نمونه کامل در `.env.example` قرار دارد.

## آپدیت بدون حذف اطلاعات

بعد از قرارگرفتن نسخه جدید روی شاخه `main` فقط این فرمان را اجرا کنید:

```bash
sudo sanashop update
```

فرمان بالا سورس را با `main` هماهنگ می‌کند، ایمیج‌ها را دوباره می‌سازد، migration و static را اجرا می‌کند و سرویس‌ها را بدون حذف volumeهای دیتابیس و تصاویر بالا می‌آورد.

```bash
sudo sanashop status
sudo sanashop logs web
sudo sanashop logs bot
sudo sanashop backup
sudo sanashop rollback
```

پشتیبان‌ها در `/opt/sanashop/backups` ذخیره می‌شوند. بهتر است این پوشه به فضای دیگری نیز منتقل شود.

## تنظیم پرداخت

در ربات: «تنظیمات فروشگاه ← روش پرداخت» را باز کنید. برای زرین‌پال، Merchant ID را هنگام نصب یا از پنل وب در بخش تنظیمات وارد کنید. مبلغ‌های سایت تومان هستند و هنگام ارسال به زرین‌پال به ریال تبدیل می‌شوند. Callback به شکل زیر است:

```text
https://YOUR-DOMAIN/payment/zarinpal/callback/
```

رسید کارت‌به‌کارت در مسیر عمومی وب سرو نمی‌شود و فقط مستقیماً برای مدیر تلگرام ارسال می‌شود.

## آمادگی اینماد

پیش از درخواست اینماد، دامنه و SSL باید فعال باشند، اطلاعات تماس و آدرس واقعی را در پنل تکمیل کنید، قوانین و رویه مرجوعی را با شرایط واقعی کسب‌وکار خودتان تطبیق دهید و سپس کد نماد را در «تنظیمات فروشگاه ← کد HTML اینماد» بگذارید. دریافت مجوز و پذیرش درگاه به مدارک و بررسی مراجع مربوط وابسته است و سورس به‌تنهایی تضمین‌کننده تأیید نیست.

## توسعه محلی

```bash
cp .env.example .env
docker compose up --build
docker compose exec web python manage.py test
```

ساختار اصلی:

- `shop/models.py`: دیتابیس فروشگاه
- `shop/views.py` و `templates/`: ویترین و خرید
- `bot.py`: پنل تلگرام
- `docker-compose.yml`: وب، ربات، PostgreSQL و Caddy
- `install.sh` و `scripts/sanashop`: نصب و نگهداری

هر تغییر دیتابیس باید migration داشته باشد:

```bash
docker compose exec web python manage.py makemigrations
docker compose exec web python manage.py migrate
```

## نکات امنیتی عملیاتی

- توکن ربات، رمز دیتابیس، کلید Django و Merchant ID را هیچ‌وقت داخل Git ثبت نکنید.
- فقط آیدی عددی مدیران واقعی را در `TELEGRAM_ADMIN_IDS` قرار دهید.
- قبل از هر آپدیت مهم `sudo sanashop backup` بگیرید.
- سیستم‌عامل و Docker را به‌روز نگه دارید و پورت PostgreSQL را عمومی نکنید.
